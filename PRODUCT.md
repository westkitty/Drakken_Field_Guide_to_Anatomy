# Drakken Field Anatomy Archive — Product Context & Mission

## 1. Product Identity & Purpose
The **Drakken Field Anatomy Archive** is an interactive, forensic 3D examination system designed for field researchers, military strategists, and civic administrators analyzing the **59 canonical Drakken entities** documented in the Skymourn Blood Eclipse compendium.

- **Primary Goal**: Provide a responsive, high-performance, 3D anatomical examination experience for analyzing colossal planetary specimens down to sub-layer structural details.
- **Context**: Operating out of **Zentrum Vault 9**, a subterranean intelligence bunker preserving recovered field data.

---

## 2. Target Audience Personas

### Alex (Power User / Tactical Analyst)
- **Needs**: Fast keyboard navigation, precise sectioning planes, multi-format data exports (Markdown & JSON), diagnostic memory readouts.
- **Key Flow**: Searches by designation (`DFA-ATM-001`), adjusts clipping plane position on `X/Y/Z` axes, inspects internal magma cores, exports structured JSON report.

### Jordan (First-Time Examiner / Civic Administrator)
- **Needs**: Intuitive visual scale comparisons (Human 1.8m, Vehicle 1.5m, Building 10m), plain-language threat indicators, clear 3D annotation popups.
- **Key Flow**: Launches application, selects scale reference figure, rotates specimen, clicks anchored 3D annotations to inspect incident logs.

### Sam (Accessibility & Low-Vision Researcher)
- **Needs**: High-contrast dark mode palette, full keyboard accessibility (`Tab`, `Space`, `R`, `Esc`), WCAG AA text compliance, `prefers-reduced-motion` auto-detection.
- **Key Flow**: Navigates using screen reader landmarks, toggles high-visibility wireframe modes, uses keyboard shortcuts to pause animation loops.

---

## 3. Core Functional Pillars
1. **Interactive 3D Examination**: Real-time canvas powered by Three.js & React Three Fiber featuring 9 procedural archetype models, clipping sectioning planes, scale reference models, and dynamic lighting.
2. **59 Canon Specimen Manifest**: Comprehensive registry covering Crust-Binders, Atmos-Engines, Seedcarriers, Fluxborne, Orbital-Wyrms, Civiformers, Noosphere-Cantors, Glitch-Touched entities, and Origin singularities.
3. **Multi-Layer Anatomical Breakdown**: Independent visibility control across 4 distinct layers: `surface`, `structure`, `internal`, and `functional`.
4. **Data Export & Reporting**: One-click generation of standardized Markdown incident dossiers and JSON records.
