# Product Definition

The Drakken Field Anatomy Archive is a single-browser forensic compendium for all 59 canonical Drakken records. Its primary journey is: find a record, inspect a record-specific 3D reconstruction, toggle four evidence layers, section the model, review annotations and incidents, compare stated evidence, and export the complete record.

## Current scope

- 59 searchable records across the complete registry
- record-specific procedural model routing
- surface, structure, internal, and functional layers
- camera presets and perspective/orthographic modes
- animation states, sectioning, measurement points, annotations, diagnostics, and exports
- local project-owned runtime geometry with no remote asset dependency

## Evidence boundary

A passing build proves source integration, not browser usability, visual fidelity, physical scale, target-device performance, or long-session resource stability. Those remain release gates.
